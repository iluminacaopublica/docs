# Formulário de Termo de Aceite de Obra de Expansão

SMOB/DIIP – Prefeitura Municipal de Foz do Iguaçu · Contrato nº 208/2025 (IP FOZ).

Página única (`index.html`) que preenche o Termo de Aceite de obras da Cota Expansão e gera o PDF com o timbrado da Prefeitura, direto no navegador. Nenhum dado é enviado a servidor.

**Uso:** abra `index.html` no Chrome, preencha os campos e clique em *Gerar PDF*.
